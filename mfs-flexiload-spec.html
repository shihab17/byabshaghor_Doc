MFS Agent / Flexiload Vertical — Spec

কাস্টমার অ্যানালিসিসে ডিমান্ড প্রমাণিত — ফার্মেসির মতোই নতুন vertical। ফ্লেক্সিলোড = API দিয়ে পুরো অটো; MFS এজেন্ট = ফ্লোট ট্র্যাকিং + USSD সেমি-অটো।

BUSINESS_CATEGORIES-এ যোগ

MFS Agent / Flexiload — business-categories.ts-এ নতুন ক্যাটাগরি (Service/Finance গ্রুপে)।

ডেটা মডেল (tenant স্কিমা)

mfs_providers          -- bKash, Nagad, Rocket agent accounts
  id, name, type ('bkash_agent'|'nagad_agent'|'rocket_agent'|'other'),
  float_balance DECIMAL, commission_rate_pct DECIMAL(5,3),
  agent_number VARCHAR(20), is_active

agent_transactions     -- প্রতিটা ক্যাশ-ইন/আউট/সেন্ড
  id, provider_id, txn_type ('cash_in'|'cash_out'|'send_money'|'bill_pay'),
  customer_phone VARCHAR(20), amount DECIMAL, commission DECIMAL,
  trxid VARCHAR(50), note, created_by, created_at

flexiload_wallets      -- প্রতি অপারেটরে রিচার্জ ব্যালেন্স
  id, operator ('GP'|'Robi'|'BL'|'Airtel'|'Teletalk'), balance DECIMAL, low_balance_alert DECIMAL

flexiload_transactions
  id, operator, phone, amount, package_id NULL, commission DECIMAL,
  txn_id VARCHAR(50), status ('pending'|'success'|'failed'|'reversed'), ref_id, created_at

ফ্লো

MFS এজেন্ট (রেকর্ড + সেমি-অটো)

  • অ্যাপে "এজেন্ট লেনদেন": প্রোভাইডার সিলেক্ট → cash-in/out → কাস্টমার নম্বর+টাকা → TrxID (ঐচ্ছিক)
  • ফ্লোট অটো-আপডেট: cash-in → float+amount, commission জমে; cash-out → float−amount
  • USSD ডিপ-লিংক: টাpan করলে tel:*247#... স্ট্রিং তৈরি হয় — এজেন্ট শুধু পিন দেয় (Android; iPhone-এ USSD স্কেম নেই — ম্যানুয়াল ফ্লো)
  • দৈনিক সেটেলমেন্ট রিপোর্ট: প্রতি প্রোভাইডারে ফ্লোট, ওই দিনের কমিশন

ফ্লেক্সিলোড (API-অটো — পরে)

  • রিসেলার অ্যাকাউন্ট (Supayo/FlexiloadBD) → api_key+secret টেন্যান্ট সেটিংসে
  • "রিচার্জ": অপারেটর+নম্বর+টাকা → API কল → txn_id সেভ → webhook/poll status
  • ব্যালেন্স কমলে alert; প্রতিটা রিচার্জে কমিশন অটো-হিসাব
  • এটা Phase-এ শেষ অংশ — আগে MFS রেকর্ডিংটা চালু

মেনু/রিপোর্ট

  • মেনু: "MFS & Flexiload" গ্রুপ → Dashboard (ফ্লোটOverview), Transactions, Providers
  • রিপোর্ট: দৈনিক কমিশন, ফ্লোট ব্যালেন্স, অপারেটরভেদে বিক্রি

সেফটি/নিয়ম

  • লেনদেন একবারই — client_ref idempotency (due-link প্যাটার্ন)
  • ফ্লেক্সিলোডে ভুল নম্বর = টাকা গায়েব → submit-এর আগে নম্বর+অপরেটর কনফার্ম স্ক্রিন
  • আমরা লেনদেন এক্সিকিউট করি না (MFS) — শুধু হিসাব+সাহায্য; টেক্সটে স্পষ্ট রাখা

রোডম্যাপ

  1. এখন: ক্যাটাগরি + টেবিল + এজেন্ট লেনদেন UI + ফ্লোট ট্র্যাকিং + দৈনিক রিপোর্ট
  2. পরে: USSD ডিপ-লিংক (Android)
  3. পরে: ফ্লেক্সিলোড অ্যাগ্রিগেটর ইন্টিগ্রেশন (রিসেলার সাইনআপ লাগে)
