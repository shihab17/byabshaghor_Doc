১. Online Shop / Facebook Seller — সবচেয়ে বড় গ্যাপ

BD-র FB/WhatsApp seller workflow: inbox-এ order → confirm → courier (Steadfast/Pathao/RedX) → COD collect → delivered/returned। এই chain-এর প্রায় কিছুই নেই।

# Gap ব্যাখ্যা সম্ভাব্য implementation
1.1 Courier integration নেই steadfast\|pathao\|redx\|ecourier\|paperfly — কোডে 0 match। Online seller-দের #1 চাহিদা। নতুন modules/courier/ — provider abstraction (Steadfast আগে, সবচেয়ে জনপ্রিয়), parcel create/track, API key per-tenant settings
1.2 Storefront নেই websites/mobile_shop/ ফাঁকা; catalog page/cart/checkout কিছুই নেই। Smart Dokani ও Hishabee-র "অনলাইন শপ" এর বিপরীতে সরাসরি গ্যাপ। Storefront MVP: public catalog (tenant subdomain), product page, cart, checkout → sale_order source='ecommerce' (infra ready)
1.3 Fulfillment pipeline নেই Order status শুধু open/invoiced/cancelled/held। confirmed→packed→courier-assigned→in-transit→delivered→returned(RTO) নেই; partial delivery নেই। sale_orders-এ fulfillment status + events table; status change webhook (partner-api/webhooks.ts reusable)
1.4 COD lifecycle নেই Advance নেওয়া যায়, কিন্তু বাকি amount courier-এর কাছে receivable হিসেবে ট্র্যাক হয় না; courier remittance reconciliation নেই। Order-এ cod_amount, courier_name, consignment_id, courier_payment_status; settlement match report
1.5 "Online Shop" business category নেই 017_create_business_categories.ts-এ Clothing Store/Jewelry Store আছে, FB seller-দের category নেই — ভুল category বেছে feature-gating-এ আটকে যাবে। Seed-এ 'Online Shop / Facebook Shop' category যোগ + ADVANCED_SHOP_CATS-এ include
1.6 Fraud/risk check নেই Steadfast fraud-check API দিয়ে phone-এর delivery success rate দেখা BD seller-দের চেনা ফিচার। Courier module-এর অংশ হিসেবে customer phone → risk score
1.7 Channel-level tracking নেই source আছে কিন্তু FB page/WhatsApp/website-level channel + channel-wise sales report নেই। sale_orders.channel (sub-source) + report filter
1.8 Customer address book নেই Order-এ delivery_address যায়, customer profile-এ multiple address + district/thana নেই (courier booking-এ must-have)। customer_addresses table (district/thana/area, is_default)
1.9 Order status auto-notification WhatsApp/SMS infra আছে; order confirm/dispatch/deliver হুক-এ auto message আছে কিনা verify করা — মনে হয় নেই। Order status event → message template (existing templates module)
1.10 Marketplace connectors নেই Daraz/Shopify/WooCommerce/FB Commerce ready connector নেই; partner API দিয়ে বানাতে হবে। Partner API + webhooks আছে; connector-গুলো phase ২

২. Clothing / Apparel — মোটামুটি ready, ছোট গ্যাপ

✅ Variant/size/color/brand/stock-aging/exchange সব আছে।

# Gap ব্যাখ্যা সম্ভাব্য implementation
2.1 Barcode/price tag label printing নেই কোডে শুধু "Print Invoice" আছে; label/sticker print কোথাও নেই। কাপড়ের দোকানে প্রতিটা আইটেমে price tag must। Label print template (size/price/SKU/barcode), thermal label printer support; templates module reuse
2.2 Exchange কেবল Mobile Shop-এর জন্য menus.ts:196 — categories: MOBILE_SHOP + Premium। Clothing-এ exchange সবচেয়ে কমন। ADVANCED_SHOP_CATS-এ scope বাড়ানো (menu seed update; admin menu editor দিয়েও যায় কিন্তু default ঠিক করা ভালো)
2.3 Style/season/collection grouping নেই স্টাইল নম্বর/সিজন অনুযায়ী stock ও sales view নেই। Product-এ style_code/collection field + filter; অথবা category hierarchy reuse
2.4 Size-grid billing view নেই Variant picker আছে, কিন্তু এক style-এর সব size একসাথে দেখে qty বসানোর matrix grid নেই। POS-এ matrix entry mode (size × qty grid) — wholesale clothing-এ খুব দরকারি
2.5 Bundle/kit product নেই Free offer আছে, "shirt+pant set" টাইপ kit নেই (sell হয় একসাথে, stock কাটে আলাদা)। Kit/bundle product type — parent SKU, component stock deduction

৩. Jewelry — functional depth সবচেয়ে কম

Jewelry Store category + variable price + Today Prices আছে — কিন্তু jewelry pricing model-ই আলাদা।

# Gap ব্যাখ্যা সম্ভাব্য implementation
3.1 Weight × rate pricing নেই price = weight (vori/gram) × daily metal rate অটো-ক্যালকুলেশন নেই। Product-এ pricing mode: fixed | variable | weight_rate; sale line-এ rate × weight compute
3.2 Making charge + wastage নেই দাম = metal value + making charge + wastage% — আলাদা price component নেই। Sale item-এ making_charge, wastage_percent fields; invoice template-এ breakdown
3.3 Purity/karat নেই 22k/21k/18k + hallmark; attribute দিয়ে ট্যাগ যায় কিন্তু pricing-aware না। Metal type + purity attribute template; rate per purity
3.4 Old gold exchange/buyback নেই পুরনো গহনা ফেরত নিয়ে নতুন বিক্রি — jewelry sale-এর ৩০-৪০%; exchange module ফোন-কেন্দ্রিক। Exchange-এ jewelry mode: weight+purity দিয়ে buyback value; category gate খোলা
3.5 Per-piece weight নেই প্রতিটা piece-এর ভিন্ন ওজন (serialized variant দরকার)। Serialized unit-এ weight field (unit-level attribute)
3.6 Live gold rate fetch নেই Today Prices হাতে update; BAJUS rate auto-fetch নেই। Daily rate source config + scheduled fetch (scraping/API availability সীমিত — manual fallback রাখুন)
3.7 Jewelry tag/memo print নেই গহনার ছোট ট্যাগ + মেমো ফরম্যাট। Label print (2.1-এর সাথে) + jewelry invoice template
3.8 Stock-by-weight report নেই মোট কত ভরি/গ্রাম মাল আছে। Stock report-এ weight column (UOM-aware)

৪. Wholesale — ভালো অবস্থায়, distribution-side ফাঁক

✅ Tier prices, credit limit + over-limit confirm, due-aging, UOM conversion, party ledger, commission — সব আছে।

# Gap ব্যাখ্যা সম্ভাব্য implementation
4.1 Customer price group নেই product_tier_prices qty-based; customer-category অনুযায়ী আলাদা price list (A-dealer/B-dealer) নেই। customer_groups + group-wise price list / discount%; sale-এ customer group দেখে price resolve
4.2 Delivery challan নেই Wholesale-এ order → challan → invoice/payment flow স্ট্যান্ডার্ড; challan document নেই। Sale order → challan document (templates module-এ নতুন doc type); partial challan ↔ invoice link
4.3 SR/route/beat management নেই Salesman commission আছে, কিন্তু route plan, area-wise order/collection, visit tracking নেই। routes/beats + customer→route mapping; SR daily order/collection report
4.4 Dispatch/delivery workflow নেই Order → dispatched → delivered status নেই (1.3-এর সাথে linked)। Fulfillment pipeline-এর wholesale flavor
4.5 MOQ/pack-size constraint নেই UOM conversion দিয়ে case sell হয়, কিন্তু min order qty/case-only enforcement নেই। Product-এ min_sale_qty, qty_step (case multiples)
4.6 Case-level scheme Free offer engine আছে; "১০ কেসে ১ ফ্রি" verify করা দরকার UOM-level কাজ করে কিনা। Free offer rule-এ UOM scope check
