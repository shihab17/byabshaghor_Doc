Interview System — Internal Spec

দোকানদার ইন্টারভিউ রেকর্ড, অ্যানালাইজ আর রিপোর্টের জন্য ইন্টারনাল টুল। যেখানে বসবে: backend public স্কিমা (টিমের ডেটা, টেন্যান্টের না) + /admin UI।

লক্ষ্য

  • ডাইনামিক প্রশ্নের ব্যাংক — নতুন প্রশ্ন যোগ/এডিট/অফ করা যায়, কোড ছাড়া
  • ইন্টারভিউ তৈরি — দোকানের তথ্য + প্রতি প্রশ্নের উত্তর + নোট
  • রিপোর্ট ডাউনলোড — CSV + সারাংশ অ্যানালিটিক্স
  • উদ্দেশ্য: metrics শিটের বদলে সিস্টেমেই ফিল্ড ডেটা — পিচে "২০টা ইন্টারভিউতে X% বলেছে Y" দেখানোর প্রুভ

ডেটা মডেল (public স্কিমা)

interview_questions
  id, text_bn, text_en, category (pain/behavior/budget/general),
  target_segment (mobile/pharmacy/all), sort_order, active bool

interviews
  id, shop_name, owner_name, phone, area, shop_type (mobile/pharmacy/other),
  uses_software (none/khata-app/pos/excel), willing_to_pay_bdt,
  pilot_interest bool, status (draft/done), note, conducted_by (user id), created_at

interview_responses
  interview_id, question_id, answer_text, pain_flag bool

API (নতুন interview মডিউল, super_admin রোল)

Method Path কাজ
GET/POST/PATCH/DELETE /api/v1/interview-questions প্রশ্নের CRUD
GET/POST /api/v1/interviews লিস্ট + তৈরি (responses-এর সাথে)
GET/PATCH /api/v1/interviews/:id দেখা/এডিট
GET /api/v1/interviews/report.csv সব ইন্টারভিউ+উত্তর CSV ডাউনলোড
GET /api/v1/interviews/stats অ্যানালিটিক্স: মোট, segment ভাগ, pain flag গণনা, willing_to_pay গড়, pilot_interest %

UI — /admin/interviews (shop-app-web)

  1. Questions ট্যাব: তালিকা + "নতুন প্রশ্ন" ডায়ালগ (bn/en, category, segment, order, active toggle)
  2. Interviews ট্যাব: লিস্ট (দোকান, এলাকা, টাইপ, তারিখ, willing_to_pay, pilot?) + নতুন ইন্টারভিউ ফর্ম — প্রশ্নগুলো অটো লোড (segment ফিল্টার), প্রতিটার নিচে টেক্সট উত্তর + pain চেকবক্স
  3. Report ট্যাব: stats কার্ড (মোট ইন্টারভিউ, সেগমেন্ট ভাগ, top pains, গড় willing_to_pay, pilot আগ্রহ %) + "Download CSV" বাটন

স্পেক নিয়ম

  • উত্তর ফ্রি-টেক্সট (MCQ না — ফিল্ডে মুখের কথা লেখা যায়)
  • pain_flag চেকবক্স প্রতি উত্তরে — stats-এ "কোন ব্যথা কতবার উঠেছে" হিসাবের জন্য
  • প্রশ্ন seed: sales-playbook.md-এর ১০+৩টা প্রশ্ন দিয়ে শুরু
  • অ্যাক্সেস: শুধু super_admin (ফাউন্ডারদের অ্যাকাউন্ট) — দোকানদার দেখে না
